## 🚀 Project Overview
EventWatch AI is an API-first, ML-driven observability platform designed to transform raw logs into actionable insights.

- **Objective**: 4-6 hour MVP for intelligent log monitoring.
- **Core Value**: Reduce Mean Time To Detection (MTTD) using automated anomaly detection.
- **Stakeholders**: SREs, DevOps Engineers, and System Architects.

## 🏗️ System Architecture
Built on a robust, scalable multi-tier architecture.

1.  **Dashboard**: Streamlit-based interactive UI.
2.  **API Layer**: FastAPI backend with asynchronous capabilities.
3.  **Service Layer**: Business logic for log parsing & anomaly detection.
4.  **Engine**: Isolation Forest (ML) + Statistical Thresholds.
5.  **Database**: PostgreSQL for persistent, structured storage.

---

## 🛠️ Technology Stack
Modern, high-performance tools for production readiness.

- **Backend**: Python 3.12, FastAPI, Pydantic v2.
- **ORM/DB**: SQLAlchemy 2.0, PostgreSQL.
- **Data Science**: Scikit-Learn (Isolation Forest), Pandas, NumPy.
- **Frontend**: Streamlit, Plotly.
- **DevOps**: Docker, Docker Compose, Pytest.

---

## 🧠 AI & Anomaly Detection
Moving beyond static thresholds with hybrid detection.

- **Statistical**: Moving average spikes and frequency patterns.
- **Machine Learning**: **Isolation Forest** algorithm.
- **Log Parsing**: Automated extraction of severity, timestamp, and message.
- **Dynamic Health**: Real-time System Health Score calculation.
